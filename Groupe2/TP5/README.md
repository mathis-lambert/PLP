# Commentaires
* Le TP m'a fait me rendre compte qu'il était difficile de manipuler les chaînes de caractères en C contrairement à python.
* Le parsing des expressions lambda est assez complexe. Il faut bien comprendre les regex et les structures de données pour réussir à les implémenter.
* Les regex en C sont compliqués car ils reposent sur les API POSIX, qui nécessitent un échappement lourd et manquent de la flexibilité et des fonctionnalités modernes des langages de haut niveau.
